# SocialSpace — Flask Social Network

## Опис проєкту

SocialSpace — вебзастосунок з елементами соціальної мережі, розроблений на основі Flask-проєкту попередніх лабораторних робіт у межах підсумкового комплексного завдання.

**Варіант:** 1 — Розроблення вебзастосунку з елементами соціальної мережі  
**Гілка:** final-project

## Функціональні можливості

- Реєстрація, автентифікація та авторизація користувачів.
- Розширені профілі користувачів.
- Підписки та відписки.
- Персоналізована стрічка публікацій.
- Створення, редагування та видалення публікацій.
- Створення, редагування та видалення коментарів.
- Реакції на публікації (Likes).
- Пошук користувачів та публікацій.
- Пагінація результатів.
- Форматування публікацій за допомогою Markdown.
- Завантаження, перевірка та оброблення зображень.
- Електронні сповіщення про лайки, коментарі та підписки.
- Розмежування прав доступу.
- Адміністративна панель.
- Категорії та хештеги.
- Власні сторінки HTTP-помилок.

## Архітектура

Застосунок має модульну структуру:

- app/users — користувачі, профілі, автентифікація та підписки.
- app/posts — публікації, коментарі, лайки, пошук та завантаження зображень.
- app/admin — адміністративна панель.
- app/products — модуль товарів із попередніх лабораторних робіт.
- app/notifications.py — електронні сповіщення.
- app/errors.py — оброблення HTTP-помилок.
- migrations — міграції бази даних.
- tests — автоматизовані тести.
- config.py — конфігурація застосунку.
- smtp_debug.py — локальний тестовий SMTP-сервер.

## Встановлення та запуск

1. Клонувати репозиторій та перейти на гілку final-project.
2. Створити віртуальне середовище: `python -m venv .venv`.
3. Активувати середовище: `.venv\Scripts\Activate.ps1`.
4. Встановити залежності: `python -m pip install -r requirements.txt`.
5. Застосувати міграції: `flask --app app db upgrade`.
6. Запустити застосунок: `flask --app app run`.
7. Відкрити http://127.0.0.1:5000.

Робоча база даних та завантажені користувачами зображення не зберігаються в репозиторії.

## Електронні сповіщення

Для локального тестування використовується SMTP-сервер, який запускається командою:

`python smtp_debug.py`

Сервер приймає електронні листи на порту 1025 та відображає їхній розшифрований вміст у терміналі.

Передбачено налаштування зовнішнього SMTP-сервера через змінні середовища. Доставка до зовнішніх поштових скриньок не тестувалася.

## Створення адміністратора

Після застосування міграцій необхідно зареєструвати користувача через вебінтерфейс.

Відкрити Flask Shell:

`flask --app app shell`

Виконати Python-команди:

```python
from app import db
from app.users.models import User

user = db.session.scalar(
    db.select(User).where(User.username == "Admin")
)

user.is_admin = True
db.session.commit()
```

Замість Admin необхідно вказати ім'я попередньо зареєстрованого користувача.

Після повторного входу до облікового запису стане доступною адміністративна панель за адресою `/management/`.
